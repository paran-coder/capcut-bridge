  2. 편집 의도를 고른 뒤 연결 분석하기를 누르세요.
  3. 추천 카드에서 이유와 수치를 확인하고 전환 길이를 비교하세요.
  4. 가이드 보기에서 내용을 확인하고 필요하면 텍스트로 저장하세요.

분석은 밝기·색감·저해상도 화면 구조·프레임 변화를 비교하는 규칙 방식입니다. 장면의 의미, 인물, 대사, 음악은 분석하지 않습니다. 화면 차이가 곧 잘못된 편집을 뜻하지는 않습니다.

프레임률은 사용자가 선택한 프로젝트 기준이며, 원본 영상 FPS를 감지한 값이 아닙니다. 미리보기는 무음으로 재생하며 캡컷 전용 효과를 정확히 재현하지 않습니다.

영상은 내 기기에 그대로

선택한 영상은 브라우저 메모리에서만 읽습니다. 파일이나 분석 프레임을 서버로 업로드하지 않습니다. 원격 AI, 추적 도구, 외부 폰트도 사용하지 않습니다.

초기화하거나 탭을 닫으면 메모리의 파일 참조를 해제합니다. 원본 파일은 변경하지 않습니다. 텍스트 저장은 사용자가 버튼을 누를 때만 실행됩니다.

웹페이지를 불러오는 정적 파일 요청은 호스팅 서버에서 처리됩니다. 참고 자료 링크는 직접 클릭할 때 외부 사이트를 엽니다.
